# 期货信号工具 · Futures Signal Tool

> **免费开源 · 单文件 · 浏览器即用 · 只报信号不下单**
>
> 一个基于《分时均线趋势》指标的期货盯盘信号提示工具。本地双击即用，也能放到网页上让手机当 App 用。不连接交易账户，不自动下单，只帮你盯盘、按指标规则给出开平仓信号提醒。

---

## 它是干什么的

你同时盯几个品种（玻璃、螺纹钢、PVC、黄金、原油、甲醇……）时，靠肉眼盯分时图很容易漏。这个工具按固定指标规则**自动算出当前该多还是该空、要不要开仓、持仓该不该强平**，并给出明确信号和提醒。

一句话：**它只负责盯盘和报信号，绝不碰你的资金和账户。**

## 核心特点

- **零依赖**：整个工具就是一个 56K 的 HTML 文件，浏览器打开就能跑，不用装任何软件、不需要账号
- **只报信号不下单**：不连券商、不自动交易，天然安全，可放心用于研究
- **跨设备**：本地电脑直接开；上传到 GitHub Pages 后手机添加到主屏幕即可当 App 用
- **多品种多月份**：黄金/原油/玻璃/螺纹钢/PVC/甲醇等 24 个常用品种内置，可自定义；主力连续自动跟随主力月
- **完整风控**：单笔止损、单日停手（设 0 = 不限），帮你守住纪律
- **信号可追溯**：今日信号记录 + 每笔平仓盈亏 + 当日累计，自动存本地、每天清理一次
- **设置自动记住**：资金、止损、合约、刷新频率、提醒开关等都在浏览器本地持久化

## 功能总览

| 模块 | 说明 |
| --- | --- |
| 指标 | 分时均线趋势（当日 VWAP=累计成交额÷成交量）；现价≥均价看多、<均价看空、贴着均价观望 |
| 开平信号 | 开多/开空；持仓中现价触碰分时均价线即强平（强平多/强平空），不自动反手 |
| 风控 | 单笔止损（设0=不限）、单日停手（设0=不限）、均价线强平 |
| 图表 | 分时图 + K线（1/5/15/30/60 分），蜡烛按指标着色、叠加当日均价线 |
| 数据 | 现价/涨跌幅/今开/最高/最低/昨结/成交量/持仓量/当日均价 |
| 持仓盈亏 | 自动记开仓价与时间、算盈亏（扣交易所手续费），可手动调开仓价 |
| 信号记录 | 今日每笔信号 + 平仓盈亏 + 当日累计，存本地、每天自动清一次，可一键清空 |
| 提醒 | 提醒音、系统通知（可选） |
| 刷新 | 10/30/60 秒或手动模式，手动模式手机端单独显示刷新按钮 |

## 快速开始（本地）

1. 下载 `期货信号工具.html`
2. 用 Chrome / Edge 等浏览器**双击打开**即可
3. 点右上角「设置」添加品种和月份；首页空状态也能「快速添加」常用品种
4. 连网即拉行情，默认每 30 秒刷新一次

## 在手机上用（网页版）

1. 把这个仓库部署到 **GitHub Pages**（仓库 Settings → Pages → 选择 main 分支）
2. 手机浏览器打开 `https://<你的用户名>.github.io/futures-signal-tool/`
3. iPhone 用 Safari 打开后点「分享 → 添加到主屏幕」，就变成一个独立 App 图标

> 说明：网页版是纯前端 + 免费行情接口，不做系统级推送；想一直收到信号提醒，建议常开或用电脑端。

## 信号规则（分时均线趋势）

- 当日均价线 = 当日累计成交额 ÷ 成交量（VWAP）
- **现价 ≥ 均价** → 偏多，出现突破即**开多**
- **现价 < 均价** → 偏空，出现突破即**开空**
- **持仓中现价触碰分时均价线** → **强平**（强平多/强平空），不自动反手
- 贴着均价（偏差 < 0.1%）→ 观望，不开仓
