# 期货信号工具（单文件 HTML 版）

一个**单文件 HTML** 的期货信号提示工具，双击用浏览器打开就能跑，**不用装任何东西**。行情数据来自新浪免费接口，联网即用。

> ⚠️ **只报信号、绝不下单**。这是辅助分析工具，不是自动交易程序，也不给任何仓位/资金建议。期货风险高，入市需谨慎，盈亏自负。

## 怎么用（1 步）
1. 双击 `期货信号工具.html`，用 Chrome / Edge 等浏览器打开即可。
2. 默认不自动带品种；点右上角「设置」，或首页空状态点「快速添加」，加自己的品种和月份。
3. 连网即拉行情，默认每 30 秒刷新一次（可在设置里改手动）；出现新信号会响铃/系统通知提醒。

## 功能
- **指标**：分时均线趋势（当日 VWAP）——现价≥均价看多、现价<均价看空、贴着均价算观望
- **开平信号**：开多/开空；持仓中现价触碰分时均价线即强平（强平多/强平空），不自动反手
- **风控**：单笔止损（设0=不限）、单日停手（设0=不限）
- **图表**：分时图 + K线（1/5/15/30/60分），K线蜡烛按指标着色、叠加当日均价线
- **数据**：今开/最高/最低/昨结/成交量/持仓量/当日均价
- **持仓盈亏**：自动记录开仓价与时间，算开仓以来盈亏（扣交易所手续费），可手动调开仓价
- **今日信号记录**：每笔平仓盈亏 + 当日累计盈亏，存本地（关掉重开不丢、每天自动清一次），可一键清空
- **反馈入口**：页面底部可去 GitHub Issues 提建议，或直接加 QQ 99405711
- **选合约**：左选品种、右选月份，自动探测当前挂牌合约，主力连续自动跟随主力月
- 设置自动记住（存在浏览器本地 localStorage）
